# Bipin Sharma — Chartered Accountant

A static website built with plain HTML, CSS, and JavaScript.

## Website source

- `index.html` — home page
- `blogs.html` — blog page
- `contact.html` — contact page
- `privacy-policy.html` — privacy policy
- `styles.css` — all website styles
- `script.js` — mobile navigation and contact form behavior
- `assets/` — website images

Open `index.html` directly or deploy the repository to any static hosting service. The `src/` directory is generated preview infrastructure and is not part of the website implementation.
